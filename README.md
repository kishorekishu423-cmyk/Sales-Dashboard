#Sales Dashboard

#Project Overview
This project is an interactive Sales Dashboard built using Microsoft Power BI. It provides insights into sales performance using charts, KPIs, and filters.

#Features
- Total Sales
- Total Profit
- Sales by Category
- Sales by Region
- Monthly Sales Trend
- Interactive Slicers

#Tools Used
- Microsoft Power BI
- Microsoft Excel

#Files
- kishore sales dashboard 2.pbix
- Sales Data.xlsx
